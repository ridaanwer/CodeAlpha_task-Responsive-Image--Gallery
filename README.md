# CodeAlpha_task-Responsive-Image--Gallery
Responsive Image Gallery 
 A modern , interactive , and responsive images Gallery web application 
 category filters, lightbox and keyboards controls built using HTML,CSS,JAVASCRIPT.
 
Live Demo: https://ridaanwer.github.io/CodeAlpha_task-Responsive-Image--Gallery/

 Features

. Grid Layout: Designed with a clean HTML and CSS layout that adjusts seamlessly.
. Lightbox Modal View: 
. Click on any image to view it in an enlarged full-screen overlay.
. Navigation Controls:
. Next and previous buttons inside the lightbox to easily browse through images.
. Interactive Hover Effects: 
. Smooth transitions and hover animations on images.
. Category Filters: Filter images dynamically by categories.
. Fully Responsive: Optimized for various screen sizes (mobile, tablet, and desktop)
